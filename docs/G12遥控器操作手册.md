# 云卓 G12 遥控器操作手册

> 面向**操作员**。只管会遥控器怎么用，不需要了解 SBUS/通道/代码等底层细节。
> 底层（通道映射、桥、调试命令）见另一份文档《G12遥控器SBUS接入说明》。

---

## 一、控件

机器人的全部操作只用到下面几个控件，其余按键/拨杆目前**不用管**（备用）：

- **E 拨杆 + F 拨杆**（两个三段开关）：**总开关** —— 决定遥控器是否有效
- **A、B、C、D 四个键**：状态推进、阻尼、急停、循环结束 —— **核心/救命**
- **G、H 两个滚轮**：配置菜单滚动（G 滚一级、H 滚二级） —— **次要**
- **左右摇杆**：控制机器人走

---

## 二、总开关（E/F 拨杆）—— 最先要知道

遥控器**只有**在下面这个组合下才有效，其它组合下**完全无控制**：

| 拨杆 | 档位 | 作用 |
|------|------|------|
| **E** | **高档**（右侧） | 总开关开（之一） |
| **F** | **低档**（左侧） | 总开关开（之二） |

> **开机默认把 E 拨到高档、F 拨到低档**，遥控器才生效；拨错档位遥控器不响应（安全）。

---

## 三、状态 / 流程

机器人有明确的运行状态，用 **连按 3 次按键** 切换（记住顺序：**待机 → 准备 → 行走**）：

| 操作 | 状态 | 机器人表现 |
|------|------|-----------|
| **连按 3 次 C** | **待机 reinit** | 空闲、不动作（日常停车位） |
| **连按 3 次 A** | **准备 ready** | 起身站立，进入"准备走动"状态 |
| **连按 3 次 B** | **行走 walk** | 开始响应摇杆，可以走路 |

**一句话流程：**
1. 连按 3 次 C → 待机（平时就停在这，最安全）。
2. 要活动了：连按 3 次 A → 起身准备。
3. 要走了：连按 3 次 B → 摇杆控制行走。

> 「连按 3 次」= 快速点按同一键 3 下（每次点完松开），不是按住不松。
> 3 次需在 1.5 秒内点完，否则从头计。

---

## 四、阻尼（连按 3 次 D）—— 常规停车

**连按 3 次 D** = **阻尼 damp**：机器人关节放松、立即停止动作，**任意状态都有效**。

- 用于日常急停、异常时卸力，是"阻尼/放松"状态。
- 从阻尼恢复：连按 3 次 C（待机）→ 连按 3 次 A（准备）→ 连按 3 次 B（行走）。

---

## 五、运动停止/恢复（A+B 长按）—— 紧急急停

遇到突发情况（要撞了、失控、不对劲），**同时按住 A 和 B，保持 3 秒**：

- 第一次 A+B 长按 3 秒 → **运动停止**（`motion_stop / stop`）。
- 再同时按住 A+B 3 秒 → **运动恢复**（`motion_stop / resume`）。
- 之后每长按一次，就在「停止 / 恢复」之间切换。

> A+B 长按是「按住满 3 秒」触发一次，与上面的「连按 3 次」不是一回事，别混淆。

---

## 六、循环结束（A 长按）

做循环动作（挥手、鼓掌、握手、灵动等）时，要优雅退出：

**单独按住 A，保持 3 秒** → **循环结束**（`finish_loop`），机器人播完当前周期后回到行走模型。

> 注意：A 长按 = 循环结束；A 连按 3 次 = 准备 ready。两者是不同操作，靠「长按 vs 连按」区分。

---

## 七、摇杆控制（行走时）

| 你要做的移动 | 操作 |
|--------------|------|
| **前进 / 后退** | **左摇杆 上 / 下** |
| **左右平移（横移）** | **左摇杆 左 / 右** |
| **左转 / 右转（转身）** | **右摇杆 左 / 右** |

- 只有机器人处于**行走（连按 3 次 B）**时摇杆才有效。
- 摇杆**回中 = 不动作**，松手即停。

---

## 八、配置菜单（G/H 滚轮）

机器人除了走路，还能切换系统配置、执行动作。用 **G/H 滚轮** 操作（总开关开启时有效）：

- **G 滚轮** 拨一下 = 切换**一级菜单**（getup / speed / nav / mode / action 循环）。
- **H 滚轮** 拨一下 = 切换当前一级下的**二级选项**，机器人播报语音确认。

> 「拨一下」= 向一边拨一下 G 或 H（弹簧自动回中）就算一次。向右=下一个、向左=上一个，到末尾自动循环。

### 菜单选项表

| 一级菜单 | 二级选项 | 说明 |
|----------|----------|------|
| **getup**（起身） | stand / lie / face | 站立 / 躺起 / 趴起 |
| **speed**（速度） | std / high | 标准速度 / 高速 |
| **nav**（导航） | manual / auto / follow | 手动 / 自动 / 跟随 |
| **mode**（模式） | rl / mix / spec / app | 强化学习 / 混合 / 特技 / 应用 |

### 动作配置（action 菜单）

把一级菜单滚到 **action** 后，用 **H 滚轮** 在动作清单里滚动选择，**按住 C 3 秒** 触发所选动作。

动作清单（平铺）：

| 类别 | 动作 |
|------|------|
| 动作类 | 比心、敬礼、打招呼、击掌、挥手、鼓掌、握手、灵动 |
| 舞蹈类 | 动太极、静太极、滑步舞蹈、相亲相爱舞蹈 |
| 特技类 | 跳远、侧空翻、前空翻、跳高、乔丹跳 |

## 九、快速操作卡（随时抄走）

```
总开关：E 拨高档 + F 拨低档（否则遥控器无效）

连按 3 次 C → 待机 reinit
连按 3 次 A → 准备 ready（起身站立）
连按 3 次 B → 行走 walk（摇杆控制移动）
连按 3 次 D → 阻尼 damp（立即停车）

向前走：左摇杆 上       左右平移：左摇杆 左/右       转身：右摇杆 左/右
停止走：摇杆 回中

【突发急停】同时按住 A+B 保持 3 秒 → 运动停止
【恢复运动】再同时按住 A+B 3 秒 → 运动恢复
【循环结束】单独按住 A 3 秒 → 循环结束

配置菜单：
  拨 G 滚轮 → 切一级菜单（getup/speed/nav/mode/action）
  拨 H 滚轮 → 切二级选项 → 机器人播报确认
  action 菜单内：按住 C 3 秒 → 触发所选动作
```

---

## 十、安全注意事项

- **开机第一件事**：确认 E 高档、F 低档（总开关开），且先停在待机（连按 3 次 C）。
- **急停要果断**：A+B 长按 3 秒，任何时候都能用。
- **进入配置菜单前先站稳**：确认机器人处于 ready/行走且地面安全再滚 G/H 菜单。
- 机器人行走或做动作时**手别离开 A/B 键附近**，随时准备急停。
- 配置或动作执行中**不要重复切换**，等它做完再继续。
