## 2. 各功能包介绍

### 2.1 `realsense2_camera` — 核心驱动

**类型:** C++ (ament_cmake)  
**入口节点:** `realsense2_camera_node`  
**功能:** 连接 Intel RealSense 硬件设备，发布彩色、深度、红外、IMU 等流数据到 ROS2 话题。

**发布的话题（默认命名空间 `/camera`）:**

| 话题 | 类型 | 说明 |
|---|---|---|
| `/camera/color/image_raw` | `sensor_msgs/Image` | 彩色图 |
| `/camera/color/camera_info` | `sensor_msgs/CameraInfo` | 彩色相机内参 |
| `/camera/depth/image_rect_raw` | `sensor_msgs/Image` | 深度图 |
| `/camera/depth/camera_info` | `sensor_msgs/CameraInfo` | 深度相机内参 |
| `/camera/infra1/image_rect_raw` | `sensor_msgs/Image` | 左红外图 |
| `/camera/infra2/image_rect_raw` | `sensor_msgs/Image` | 右红外图 |
| `/camera/gyro/imu_info` | `realsense2_camera_msgs/IMUInfo` | 陀螺仪信息 |
| `/camera/accel/imu_info` | `realsense2_camera_msgs/IMUInfo` | 加速度计信息 |
| `/camera/gyro/sample` | `sensor_msgs/Imu` | 陀螺仪数据 |
| `/camera/accel/sample` | `sensor_msgs/Imu` | 加速度计数据 |
| `/camera/extrinsics/depth_to_color` | `realsense2_camera_msgs/Extrinsics` | 深度到彩色的外参 |
| `/camera/pointcloud` | `sensor_msgs/PointCloud2` | 点云（需开启 `pointcloud.enable:=true`） |
| `/camera/aligned_depth_to_color/image_raw` | `sensor_msgs/Image` | 对齐到彩色视角的深度图（需开启 `align_depth.enable:=true`） |
| `/camera/colorized_depth/image_raw` | `sensor_msgs/Image` | 深度伪彩图（需开启 `colorizer.enable:=true`） |

### 2.2 `realsense2_camera_msgs` — 自定义消息

**类型:** 纯消息定义包  
**功能:** 定义了 `realsense2_camera` 节点使用的自定义消息类型：
- `IMUInfo` — IMU 信息（含噪声密度、量程等）
- `Extrinsics` — 相机间外参（旋转矩阵 + 平移向量）
- `RGBD` — 融合的彩色+深度消息（`realsense2_rgbd_plugin` 使用）

### 2.3 `realsense2_description` — URDF 模型

**类型:** 纯描述包  
**功能:** 提供 RealSense 各型号相机的 URDF 模型文件，用于在 RViz 中可视化相机外观。  
**Launch 文件:** `view_model.launch.py` — 在 RViz 中加载显示相机 3D 模型，无需连接硬件。

### 2.4 `realsense2_rgbd_plugin` — RViz RGB-D 可视化插件

**类型:** C++ RViz 插件库  
**功能:** 在 RViz 中显示 `RGBD` 消息（彩色图与深度图并排或叠加显示）。支持可配置的伪彩色映射（Jet/灰度）、深度范围裁剪、Alpha 叠加和 180° 旋转。

**注意:** 这是一个**纯可视化工具**，不影响数据输出。如果不需要在 RViz 中看 RGB-D 融合显示，**可以完全忽略此包**。

**CMake 编译开关:** `RVIZ_RGBD_PLUGIN`（默认 OFF），需显式开启：
```bash
colcon build --cmake-args '-DRVIZ_RGBD_PLUGIN=ON'
```

### 2.5 `realsense2_ros_mqtt_bridge` — MQTT 桥接

**类型:** Python (ament_python)  
**功能:** 将 RealSense 相机的 ROS2 接口桥接到 MQTT 协议，使得**非 ROS 客户端**（手机 App、云端服务、边缘设备等）可以通过标准 MQTT 协议获取摄像头数据和参数控制。

**适用场景:**
- ✅ 手机 App 远程查看摄像头画面
- ✅ 云端平台远程监控和控制
- ✅ 非 ROS 系统集成 RealSense 数据
- ❌ 本地 ROS2 节点直接访问（直接用话题订阅即可，不需要此包）

**核心通信模式:**

```
MQTT Client (App/云端)  ←→  MQTT Broker (mosquitto)  ←→  MQTT Bridge Node  ←→  realsense2_camera_node
```

**注意:** 此包默认被 `CATKIN_IGNORE` 文件排除编译（因为依赖 `paho-mqtt` 第三方库），需删除该文件后重新编译：
```bash
rm realsense2_ros_mqtt_bridge/CATKIN_IGNORE
colcon build --packages-select realsense2_ros_mqtt_bridge
```

## 3. Launch 文件详解与参数配置

所有 launch 文件位于 `realsense2_camera/launch/`。

### 3.1 `rs_launch.py` — 单摄像头标准启动（最常用）

**用途:** 启动单个 RealSense 摄像头节点，支持所有流和滤波器配置。

**基本用法:**
```bash
ros2 launch realsense2_camera rs_launch.py
```

**核心参数:**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `camera_name` | `camera` | ROS 节点名称 |
| `camera_namespace` | `camera` | ROS 命名空间 |
| `serial_no` | `''` | 按序列号选择设备（多摄像头时必填） |
| `usb_port_id` | `''` | 按 USB 端口选择设备 |
| `device_type` | `''` | 按设备类型选择，如 `d4xx`, `l5xx` |
| `enable_color` | `true` | 开启彩色流 |
| `enable_depth` | `true` | 开启深度流 |
| `enable_infra` | `false` | 开启 infrared 流（infra0） |
| `enable_infra1` | `false` | 开启左红外流 |
| `enable_infra2` | `false` | 开启右红外流 |
| `enable_gyro` | `false` | 开启陀螺仪流 |
| `enable_accel` | `false` | 开启加速度计流 |
| `enable_motion` | `false` | 开启 DDS 设备运动流 |
| `enable_sync` | `false` | 帧同步 |
| `enable_rgbd` | `false` | 发布 RGB-D 融合话题 |
| `enable_safety` | `false` | 开启 safety 流（D500 系列） |
| `enable_labeled_point_cloud` | `false` | 开启标签化点云（D500 系列） |
| `enable_occupancy` | `false` | 开启 occupancy 流（D500 系列） |

**分辨率/格式参数:**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `rgb_camera.color_profile` | `0,0,0` | 彩色分辨率 `宽,高,帧率`（如 `640,480,30`） |
| `rgb_camera.color_format` | `RGB8` | 彩色格式 |
| `depth_module.depth_profile` | `0,0,0` | 深度分辨率 `宽,高,帧率`（如 `640,480,30`） |
| `depth_module.depth_format` | `Z16` | 深度格式 |
| `depth_module.infra_profile` | `0,0,0` | 红外分辨率 |
| `gyro_fps` | `0` | 陀螺仪采样率 |
| `accel_fps` | `0` | 加速度计采样率 |

**滤波器参数:**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `align_depth.enable` | `false` | 深度对齐到彩色 |
| `colorizer.enable` | `false` | 深度伪彩化 |
| `pointcloud.enable` | `false` | 点云生成 |
| `pointcloud.ordered_pc` | `false` | 有序点云 |
| `pointcloud.stream_filter` | `2` | 点云纹理流（0=深度, 1=彩色, 2=纹理） |
| `pointcloud.stream_index_filter` | `0` | 纹理流索引 |
| `decimation_filter.enable` | `false` | 下采样滤波器 |
| `spatial_filter.enable` | `false` | 空间滤波器 |
| `temporal_filter.enable` | `false` | 时序滤波器 |
| `hole_filling_filter.enable` | `false` | 空洞填充滤波器 |
| `disparity_filter.enable` | `false` | 视差滤波器 |
| `hdr_merge.enable` | `false` | HDR 融合（需 `depth_module.hdr_enabled:=true`） |
| `rotation_filter.enable` | `false` | 旋转滤波器 |
| `rotation_filter.rotation` | `0.0` | 旋转角度（0/90/-90/180） |

**IMU 参数:**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `unite_imu_method` | `0` | IMU 融合方式: 0=None, 1=copy, 2=linear_interpolation |
| `angular_velocity_cov` | `0.01` | 角速度协方差 |
| `linear_accel_cov` | `0.01` | 线加速度协方差 |

**其他常用参数:**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `initial_reset` | `false` | 启动时复位设备 |
| `clip_distance` | `-2.0` | 最大深度距离（米），负值=不裁剪 |
| `log_level` | `info` | 日志级别: DEBUG, INFO, WARN, ERROR, FATAL |
| `output` | `screen` | 节点输出: screen, log |
| `publish_tf` | `true` | 发布 TF 变换 |
| `tf_publish_rate` | `0.0` | TF 发布频率（0=仅发布静态 TF） |
| `wait_for_device_timeout` | `-1.0` | 等待设备连接超时（秒），负值=无限等待 |
| `reconnect_timeout` | `6.0` | 断连后的重连等待时间（秒） |
| `config_file` | `''` | YAML 配置文件路径 |
| `json_file_path` | `''` | 高级 JSON 配置 |
| `rosbag_filename` | `''` | 从 ROS bag 回放数据（代替物理设备） |
| `base_frame_id` | `link` | 相机根坐标系 |
| `tf_prefix` | `''` | TF 坐标系前缀 |
| `diagnostics_period` | `0.0` | 诊断信息发布频率（0=禁用） |

**完整示例:**
```bash
ros2 launch realsense2_camera rs_launch.py \
  camera_name:=d435i \
  camera_namespace:=sensor \
  enable_color:=true \
  enable_depth:=true \
  enable_infra:=false \
  enable_gyro:=true \
  enable_accel:=true \
  unite_imu_method:=1 \
  rgb_camera.color_profile:=640,480,30 \
  depth_module.depth_profile:=640,480,30 \
  align_depth.enable:=true \
  pointcloud.enable:=false \
  clip_distance:=3.0 \
  publish_tf:=true \
  log_level:=info
```

### 3.2 `rs_multi_camera_launch.py` — 双摄像头启动

**用途:** 同时启动两台物理 RealSense 摄像头，并发布二者之间的静态 TF 变换。

**注意:** 物理上需要两台独立的 RealSense 设备，**不是**单台设备内部的双目。

**额外参数（带后缀 `1`/`2` 区分摄像头）:**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `camera_name1` / `camera_name2` | `camera1` / `camera2` | 节点名称 |
| `camera_namespace1` / `camera_namespace2` | `camera1` / `camera2` | 命名空间 |

同时继承 `rs_launch.py` 的全部参数，分别加后缀 `1` 和 `2`。例如：
- `serial_no1` / `serial_no2` — 按序列号选择设备
- `enable_depth1` / `enable_depth2` — 分别控制深度流
- `depth_module.depth_profile1` / `depth_module.depth_profile2` — 分别设置分辨率

**示例:**
```bash
ros2 launch realsense2_camera rs_multi_camera_launch.py \
  camera_name1:=cam_left \
  camera_name2:=cam_right \
  serial_no1:="'_031422250097'" \
  serial_no2:="'_336222301921'" \
  enable_color1:=true \
  enable_color2:=false \
  enable_depth1:=true \
  enable_depth2:=true
```

### 3.3 `rs_multi_camera_launch_sync.py` — 双摄像头硬件同步启动

**用途:** 启动两台摄像头并配置硬件同步模式（需 sync 线缆连接）。一台设为 Master，一台设为 Slave，确保同时捕获。

**额外参数:**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `camera_name1` / `camera_name2` | `camera1` / `camera2` | 节点名 |
| `camera_namespace1` / `camera_namespace2` | `camera1` / `camera2` | 命名空间 |
| `depth_module.inter_cam_sync_mode1` | `1` | 设备1同步模式: 0=Default, 1=Master, 2=Slave |
| `depth_module.inter_cam_sync_mode2` | `2` | 设备2同步模式: 0=Default, 1=Master, 2=Slave |

同样继承 `rs_launch.py` 的全部参数并加后缀 `1`/`2`。

**示例:**
```bash
ros2 launch realsense2_camera rs_multi_camera_launch_sync.py \
  camera_name1:=cam_master \
  camera_name2:=cam_slave \
  serial_no1:="'_031422250097'" \
  serial_no2:="'_336222301921'" \
  depth_module.inter_cam_sync_mode1:=1 \
  depth_module.inter_cam_sync_mode2:=2
```

验证同步模式：
```bash
ros2 param get /camera/cam_master depth_module.inter_cam_sync_mode
ros2 param get /camera/cam_slave depth_module.inter_cam_sync_mode
```

## 4. 机器人强化学习模型输入参数配置

### 4.1 基础配置（仅深度图）

对于强化学习模型，通常只需要深度图作为环境观测，不需要彩色图和点云等额外数据。推荐的最小化配置：

```bash
ros2 launch realsense2_camera rs_launch.py \
  enable_color:=false \
  enable_depth:=true \
  enable_infra:=false \
  enable_gyro:=false \
  enable_accel:=false \
  depth_module.depth_profile:=640,480,30 \
  depth_module.depth_format:=Z16 \
  pointcloud.enable:=false \
  align_depth.enable:=false \
  clip_distance:=3.0 \
  enable_sync:=false \
  publish_tf:=false \
  log_level:=warn
```

### 4.2 含彩色图 + 对齐深度（用于 RGB-D 观测）

如果模型需要彩色和对齐深度作为多通道输入：

```bash
ros2 launch realsense2_camera rs_launch.py \
  enable_color:=true \
  rgb_camera.color_profile:=640,480,30 \
  rgb_camera.color_format:=RGB8 \
  enable_depth:=true \
  depth_module.depth_profile:=640,480,30 \
  depth_module.depth_format:=Z16 \
  align_depth.enable:=true \
  clip_distance:=3.0 \
  enable_color:=true \
  enable_sync:=true \
  log_level:=warn
```

### 4.3 含 IMU 数据（用于需要本体感知的模型）

```bash
ros2 launch realsense2_camera rs_launch.py \
  enable_color:=false \
  enable_depth:=true \
  depth_module.depth_profile:=640,480,30 \
  enable_gyro:=true \
  gyro_fps:=400 \
  enable_accel:=true \
  accel_fps:=200 \
  unite_imu_method:=1 \
  clip_distance:=3.0 \
  log_level:=warn
```

### 4.4 与 Isaac Sim / Gazebo 联合仿真

如果在仿真环境中使用（与实际物理相机不同），通过 `rosbag_filename` 回放录制的数据：

```bash
ros2 launch realsense2_camera rs_launch.py \
  rosbag_filename:=/path/to/recorded_data.bag \
  enable_depth:=true \
  enable_color:=false
```

### 4.5 关键参数说明

| 参数 | 推荐值 | 理由 |
|---|---|---|
| `enable_color` | 按需 | 如果模型只用深度可以关掉，降低 CPU/GPU 占用 |
| `clip_distance` | 2.0~5.0 | 截断远端无效深度，减少噪声 |
| `align_depth.enable` | 按需 | 如果不需要彩色对齐深度可以关掉 |
| `publish_tf` | 按需 | 如果不需要坐标变换可以关掉减少开销 |
| `depth_module.depth_profile` | `640,480,30` 或 `848,480,30` | 较高分辨率有利于模型细节感知，但需评估性能 |
| `pointcloud.enable` | `false` | RL 一般不直接使用点云 |
| `log_level` | `warn` | 减少日志输出，降低 I/O 开销 |

### 4.6 ROS2 话题订阅示例（Python）

```python
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
import cv2
import numpy as np
from cv_bridge import CvBridge

class DepthSubscriber(Node):
    def __init__(self):
        super().__init__('depth_subscriber')
        self.bridge = CvBridge()
        self.sub = self.create_subscription(
            Image, '/camera/depth/image_rect_raw', self.depth_callback, 10)

    def depth_callback(self, msg):
        depth_image = self.bridge.imgmsg_to_cv2(msg, desired_encoding='passthrough')
        # depth_image 为 numpy 数组，单位 mm
        # 归一化到 [0, 1] 供模型使用（需先裁剪 clip_distance）
        depth_normalized = np.clip(depth_image / 1000.0 / 3.0, 0, 1)
        # depth_normalized 即可作为模型输入

def main():
    rclpy.init()
    node = DepthSubscriber()
    rclpy.spin(node)
```

## 5. MQTT 通信配置与测试

### 5.1 概述

`realsense2_ros_mqtt_bridge` 允许非 ROS 客户端（手机 App、云端、Web 后端等）通过 MQTT 协议与 RealSense 摄像头交互。

**架构:**
```
MQTT Client ←→ MQTT Broker ←→ MQTT Bridge ←→ realsense2_camera_node
```

### 5.2 前置条件

**安装 paho-mqtt:**
```bash
pip3 install paho-mqtt
```

**安装 mosquitto（MQTT Broker):**
```bash
sudo apt install mosquitto
sudo systemctl start mosquitto
sudo systemctl enable mosquitto   # 开机自启

# 验证服务状态
systemctl status mosquitto
```

### 5.6 Python 客户端测试代码

参考官方示例 `examples/minimal_mqtt_client.py`：

```python
import json
import time
import paho.mqtt.client as mqtt

class CameraMQTTClient:
    def __init__(self, broker_ip='localhost', broker_port=1883):
        self.client = mqtt.Client()
        self.client.on_connect = self.on_connect
        self.client.on_message = self.on_message
        self.client.connect(broker_ip, broker_port)
        self.response = None

    def on_connect(self, client, userdata, flags, rc):
        print(f"Connected: {rc}")
        # 订阅所有响应话题
        for suffix in ['enumerate_devices', 'get_device_info', 'get_param',
                       'set_param', 'get_frame', 'get_transformation',
                       'send_hw_reset', 'send_hwm_command']:
            client.subscribe(f'{suffix}_response')

    def on_message(self, client, userdata, msg):
        self.response = msg.payload.decode('utf-8')
        print(f"[{msg.topic}] {self.response[:200]}...")

    def publish(self, topic, data):
        self.response = None
        self.client.publish(topic, json.dumps(data))
        # 等待响应（简单实现）
        timeout = 5
        while self.response is None and timeout > 0:
            time.sleep(0.1)
            timeout -= 0.1

    def start(self):
        self.client.loop_start()
        time.sleep(1)

    def stop(self):
        self.client.loop_stop()


if __name__ == '__main__':
    cam = CameraMQTTClient()
    cam.start()

    # 枚举设备
    cam.publish('enumerate_devices_request', {
        'camera_namespace_prefix': 'camera',
        'camera_name_prefix': 'camera'
    })

    # 获取深度帧
    cam.publish('get_frame_request', {
        'camera_namespace': 'camera',
        'camera_name': 'camera',
        'stream_name': 'depth'
    })

    cam.stop()
```
